# Security policy

SoloTrace is a private beta with no hosted SoloTrace service.

## Report a vulnerability

Open a private security advisory from this repository's **Security** tab. Do not
file a public issue, paste secrets into logs, or attach audio/project data.
Include:

- affected SoloTrace version and build ID;
- macOS version;
- concise reproduction steps;
- impact and whether local project data or an MVSep key may be exposed; and
- the redacted diagnostics ZIP, only after inspecting its contents.

Reports are acknowledged as capacity allows. No response or remediation SLA is
promised during private beta.

## Supported versions

Only the newest private-beta build is supported. Replace older builds before
testing a report. Project data remains in
`~/Library/Application Support/SoloTrace` when the app is replaced.
